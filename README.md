# プロンプトビルダー

用途を選んで内容を入れるだけで、AIに貼るプロンプトを組み立てる単体HTMLツール（26プリセット）。外部ライブラリ・サーバー不要。`プロンプトビルダー.html` をブラウザで開くだけで動く。GitHub: mkt918/prompt-template-builder

## 背景
2026-07-27 に `00_作業` の単発タスク「プロンプト定型文作成ツール」として着手。要望が段階的に高度化し、git で継続的に直して GitHub に push する運用になったため、2026-10-05 にプロダクトへ昇格した。経緯・各版の変更・設計判断は `まとめ.md`（開発ログ）にある。

## 構成
- `プロンプトビルダー.html` — 本体（正本）。HTML・CSS・JS・raw テンプレートが1ファイルに入る
- `index.html` — 本体へのリダイレクト（Pages 用）
- `まとめ.md` — 開発ログ。v2〜v24 の経緯と、特記事項（設計上の注意）
